# ديوانية بلس (Diwaniya+)

منصة ألعاب جماعية: متجر فيه 24 لعبة، وحسابات بالإيميل، ومحفظة أقيام، ولوحة إدارة للمالك.
الموقع يشتغل على **Cloudflare Workers**، وقاعدة البيانات **Cloudflare D1**.

## هيكل المشروع

| المسار | الوصف |
|---|---|
| `public/` | صفحة المتجر وملفاتها العامة (أي أحد يقدر يفتحها) |
| `games/` | ملفات الألعاب الـ24. **خاصة**، ما تنفتح إلا عن طريق الخادم بعد تشغيل مدفوع أو تجربة مجانية |
| `worker/src/` | كود الخادم: الدخول، المحفظة، تشغيل الألعاب، لوحة الإدارة |
| `worker/src/seed.json` | البيانات الافتراضية (الألعاب، الباقات، الفئات) قبل أي تعديل من لوحة الإدارة |
| `worker/src/rooms/` | خوادم الغرف الجماعية (Durable Objects) |
| `scripts/build-room-engines.mjs` | ينسخ محركات ألعاب الغرف من ملفات الألعاب للخادم |
| `migrations/` | جداول قاعدة البيانات |
| `wrangler.toml` | إعدادات Cloudflare |

## كيف يحمي الخادم المنصة

- **رمز الدخول (OTP)** يوصل على الإيميل فعلاً عن طريق Resend، وما يطلع في الصفحة أبداً. ينحفظ في القاعدة مشفّر (hash)، وصالح 5 دقائق.
- **حدود للمحاولات:** 5 رموز كل 15 دقيقة لكل إيميل، و20 رمز في الساعة لكل جهاز. بعد 5 محاولات خاطئة ينقفل الدخول 15 دقيقة.
- **الجلسة** في كوكي `HttpOnly` ما يقدر يقرأه أي كود في الصفحة، وكل عملية تعدّل بيانات تحتاج رمز حماية (CSRF).
- **المالك** يتحدد من إعداد `OWNER_EMAILS` في Cloudflare، مو من الكود. ما فيه إيميل مالك مكتوب داخل الملفات.
- **الرصيد والتجارب المجانية** محسوبة في الخادم:
  - الخصم يصير مرة وحدة في عملية واحدة، فما يقدر أحد يصرف أكثر من رصيده حتى لو ضغط أكثر من مرة في نفس اللحظة.
  - الضغط مرتين على نفس اللعبة ما يخصم مرتين.
- **الألعاب** ما تنرسل للمتصفح إلا بتصريح مؤقت (12 ساعة) يطلع بعد الخصم أو التجربة المجانية، ومربوط بحساب اللاعب نفسه.
- **أسئلة تحدي الثمانية وإجاباتها** ما تطلع في المتجر. تنرسل للعبة وقت التشغيل بس، والمالك يشوفها في لوحة الإدارة.

## الغرف الجماعية والـ QR

فيه 3 أنواع غرف، وكلها تشتغل على **Durable Objects** في Cloudflare. هذي متاحة في الخطة المجانية، وما تحتاج إعداد إضافي غير `wrangler deploy`.

| النوع | الألعاب | كيف يشتغل |
|---|---|---|
| **محرك الغرف** | الدخيل، المافيا، قفطة، المستشار السري | الخادم يشغّل نفس محرك اللعبة الموجود في ملفها، وكل لاعب يلعب من جواله. المضيف (اللي شغّل اللعبة ودفع) هو بس اللي يقدر ينشئ غرفة. الضيوف يدخلون بالرمز أو الـ QR بدون حساب. |
| **جرس تحدي الثمانية** | تحدي الثمانية | خادم وسيط ينقل ضغطات الجرس بين الجوالات وشاشة اللعب. صفحة الضيف تنفتح بدون بنك الأسئلة. |
| **غرفة المتجر** | أي لعبة (زر «غرفة QR والجرس») | المضيف المسجّل ينشئ غرفة برمز من 6 خانات. اللاعبين يمسحون الـ QR، ويضغطون الجرس ويرسلون إجابات وتصويت. الخادم هو اللي يحدد من ضغط الجرس أول. |

- **رابط الضيف** (`/play/<لعبة>?room=رمز`) ما يفتح إلا والغرفة شغالة، فرابط قديم ما يفتح اللعبة ببلاش.
- **زر «🤖 تجربة مع بوتات»** في شريط اللعبة يرجّع ألعاب المحرك للوضع التجريبي القديم، عشان المضيف يجرّب لحاله.
- **إذا عدّلت ملف لعبة من ألعاب المحرك الأربع**، شغّل `node scripts/build-room-engines.mjs` قبل النشر عشان الخادم ياخذ نفس القوانين.

## الدفع (Moyasar)

1. الزبون يضغط «اشترِ الآن». الخادم ينشئ طلب بحالة `pending` وفاتورة في Moyasar. **السعر يجي من قائمة الباقات في الخادم**، مو من المتصفح.
2. الزبون يتحول لصفحة الدفع في Moyasar (مدى، Apple Pay، بطاقات ائتمانية). بيانات البطاقة ما تمر على موقعك أبداً.
3. بعد الدفع، Moyasar يرجّع الزبون لـ `/payments/return`، ويرسل إشعار (webhook) لـ `/api/payments/webhook`.
4. في الحالتين، الخادم **يسأل Moyasar مباشرة** عن الفاتورة، وما يضيف الأقيام إلا إذا كانت مدفوعة بنفس المبلغ والعملة. الإضافة تصير مرة وحدة بس، حتى لو وصل الإشعار أكثر من مرة.
5. لو ضاع الإشعار وسكّر الزبون الصفحة، الطلب ينراجع تلقائياً أول ما يفتح الموقع مرة ثانية (خلال يومين من الطلب). وفيه زر «تحقق من البوابة» في لوحة المالك ← المدفوعات.

**الاسترجاع:** يتم من لوحة Moyasar، وبعدها تخصم الأقيام يدوياً من لوحة المالك ← المستخدمين والأرصدة، مع كتابة السبب.

## النشر لأول مرة

تحتاج حساب [Cloudflare](https://dash.cloudflare.com) مجاني، وحساب [Resend](https://resend.com) مجاني لإرسال الإيميلات. Node.js لازم يكون الإصدار 20 أو أحدث.

```bash
npm install
npx wrangler login

# 1) إنشاء قاعدة البيانات، ثم انسخ database_id اللي يطلع لك وحطه في wrangler.toml
npx wrangler d1 create diwaniya-plus

# 2) إنشاء الجداول
npm run db:migrate:remote

# 3) الأسرار (كل أمر يطلب منك تلصق القيمة)
npx wrangler secret put AUTH_SECRET      # نص عشوائي طويل، مثلاً ناتج: openssl rand -base64 48
npx wrangler secret put RESEND_API_KEY   # من لوحة Resend
npx wrangler secret put MOYASAR_SECRET_KEY      # المفتاح السري من لوحة Moyasar (ابدأ بـ sk_test_ للتجربة)
npx wrangler secret put MOYASAR_WEBHOOK_SECRET  # كلمة سر تختارها أنت، وتكتبها نفسها في Moyasar (الخطوة 6)

# 4) عدّل [vars] في wrangler.toml:
#    OWNER_EMAILS = "your@email.com"
#    MAIL_FROM    = "Diwaniya Plus <login@your-domain.com>"   (لازم الدومين يكون موثّق في Resend)

# 5) النشر
npm run deploy
```

بعد النشر، اربط الدومين من لوحة Cloudflare: **Workers & Pages ← diwaniya-plus ← Settings ← Domains & Routes**.

```
# 6) في لوحة Moyasar ← Settings ← Webhooks أضف:
#    URL:          https://your-domain.com/api/payments/webhook
#    Secret token: نفس قيمة MOYASAR_WEBHOOK_SECRET
#    Events:       payment_paid و payment_failed
```

جرّب بمفاتيح الاختبار (`sk_test_`) وبطاقات Moyasar التجريبية أول. إذا كل شي زبط، بدّل للمفتاح الحقيقي (`sk_live_`) بنفس الأمر `wrangler secret put`.

> قبل التشغيل الحقيقي، عبّي الخانات المظللة في صفحات `public/legal/` (اسم المنشأة، السجل التجاري، التواصل) وراجعها مع مستشار قانوني.

## التشغيل على جهازك للتجربة

اعمل ملف `.dev.vars` في جذر المشروع. هذا الملف ما يترفع لـ GitHub:

```
AUTH_SECRET="local-dev-secret-change-me-0123456789"
DEV_MODE="true"
OWNER_EMAILS="you@example.com"
```

بعدين شغّل:

```bash
npm run db:migrate:local
npm run dev
```

افتح `http://localhost:8787`. في وضع التجربة، رمز الدخول **يطلع في الطرفية (terminal)** اللي شغّلت فيها الأمر، مو في الصفحة.

> ⚠️ لا تحط `DEV_MODE = "true"` في الموقع الحقيقي.

## الواجهة البرمجية (API)

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/catalog` | الألعاب والباقات والفئات (بدون أسئلة) |
| GET | `/api/me` | المستخدم الحالي ومحفظته |
| POST | `/api/auth/otp/send` | إرسال رمز الدخول |
| POST | `/api/auth/otp/verify` | التحقق من الرمز وفتح جلسة |
| POST | `/api/auth/logout` | تسجيل الخروج |
| POST | `/api/games/:slug/launch` | تشغيل لعبة (خصم أو تجربة مجانية) ويرجع رابط لعب مؤقت |
| GET | `/play/:slug?t=…` | ملف اللعبة نفسه، لصاحب التصريح فقط |
| POST | `/api/payments/orders` | إنشاء طلب شراء وفاتورة في Moyasar، ويرجع رابط صفحة الدفع |
| GET | `/api/payments/orders/:id` | حالة طلب الزبون نفسه (ويتحقق من البوابة إذا كان معلّق) |
| POST | `/api/payments/webhook` | إشعارات Moyasar |
| GET | `/payments/return` | رجوع الزبون من صفحة الدفع |
| POST | `/api/suggestions` | اقتراح لعبة |
| POST | `/api/rooms` | إنشاء غرفة متجر (للمستخدم المسجّل) |
| GET | `/api/rooms/status?code=…` | هل الغرفة موجودة |
| WS | `/rooms/buzz/:code/ws` | اتصال غرفة المتجر |
| WS | `/rooms/game/:slug/ws` | اتصال ألعاب المحرك (`?t=` للمضيف) |
| WS | `/rooms/relay/ws?room=…` | جرس تحدي الثمانية |
| GET | `/api/admin/data` | للمالك: المستخدمين والمدفوعات والسجل |
| GET | `/api/admin/eight-category/:slug` | للمالك: أسئلة فئة من تحدي الثمانية |
| POST | `/api/admin/action` | للمالك: تعديل الرصيد، الباقات، الألعاب، المحتوى |

## الباقي (المراحل الجاية)

- **الألعاب الـ19 الباقية:** شاشة "جوالي" فيها تشتغل على نفس الجهاز. تقدر تستخدم معها **غرفة المتجر** للجرس والإجابات من الجوالات.
