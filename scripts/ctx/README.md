# بيانات لعبة «حامي بارد»

1. `vocab.py`: يبني قائمة الكلمات من `wordfreq` (العربي) مع كلمات خليجية.
2. `embed3.py <qwenI|bge|gemma>`: يحسب معاني الكلمات بثلاث نماذج Workers AI. يحتاج نقطة مؤقتة في الـ Worker تشغّل `env.AI.run` (انشالت بعد الاستخدام).
3. `build.py`: يدمج النماذج الثلاثة ويطلّع:
   - `worker/src/ctx/vocab.txt`: الكلمات.
   - `worker/src/ctx/emb.bin`: معاني مضغوطة (PCA 64 بعد، int8) للكلمات البعيدة.
   - `worker/src/ctx/top.bin`: أقرب ١٥٠٠ كلمة لكل كلمة سرية (مرتبة بدقة، مع خصم للكلمات اللي تشبه بالحروف بس).

الكلمات السرية في `secrets.txt`.
